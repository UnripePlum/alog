GitHub 릴리즈 다운로드

창을 닫아도,
실제 페이지를 엽니다.

본인이 운영하는 사이트가 살아 있는지, 이 Mac의 브라우저로 점검합니다. 주소는 설치한 사람이 넣습니다.

macOS용 다운로드 릴리즈 노트

설치

  1. dmg를 열고 Alog.app을 Applications로 끌어다 놓습니다.
  2. 처음엔 우클릭 → 열기 (공증 전이라 macOS가 한 번 막습니다).
  3. 사이트 추가 (⌘N). 넣는 순간 이 맥의 브라우저로 실제 페이지를 엽니다.

요구 사항

용도

본인이 소유·운영하거나 모니터링 권한이 있는 사이트만. 조회수 조작이나 봇 탐지 회피는 범위가 아닙니다.

이후 버전은 앱 설정 → 업데이트에서 GitHub Releases zip을 받아 교체합니다.
