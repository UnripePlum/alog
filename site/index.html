Alog
GitHub 릴리즈

이 맥의 브라우저로
사이트가 살아 있는지 봅니다.

창을 닫아도 WebKit이 실제 페이지를 엽니다. 넣는 주소는 설치한 사람이 정합니다.

다운로드

  1. 1

    dmg를 열고 Alog.app을 Applications로 넣습니다.

  2. 2

    처음엔 우클릭 → 열기. 공증 전이라 macOS가 한 번 막습니다.

  3. 3

    ⌘N으로 사이트를 추가하면 바로 이 맥에서 페이지를 엽니다.

본인이 소유·운영하거나 모니터링 권한이 있는 사이트만. 조회수 조작, 봇 탐지 회피는 안 합니다.

이후 버전은 설정 → 업데이트에서 GitHub Releases zip으로 교체합니다.
